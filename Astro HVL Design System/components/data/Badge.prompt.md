A mono-caps status label for flight status, subsystem state, or categories.

```jsx
<Badge variant="success" dot>Flight ready</Badge>
<Badge variant="warning">Hold</Badge>
<Badge variant="brand" solid>Active</Badge>
```

Variants: `neutral` · `brand` · `success` · `warning` · `danger` · `cyan`. `solid` for filled, `dot` for a leading status dot. Keep text short (1–2 words).
